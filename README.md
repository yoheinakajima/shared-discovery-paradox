# The Shared Discovery Paradox

**How a one-answer rule turns better information into worse search.**

A group can become better informed and *less* likely to discover what it is
looking for. This repository contains the paper, an exact verification script
that reproduces every number in it, the underlying data, and an interactive
visual guide.

**Interactive guide:** https://yoheinakajima.github.io/shared-discovery-paradox/
**Paper (SSRN):** link forthcoming · **PDF:** [`paper/The_Shared_Discovery_Paradox.pdf`](paper/The_Shared_Discovery_Paradox.pdf)

## The benchmark in one table

Sixteen boxes, one jackpot, eight searchers, noisy clues (each names the
right box with probability 0.20). Same information, different action
protocols:

| Protocol | Information | Discovery | Distinct actions |
|---|---|---|---|
| Consensus (all repeat the pooled mode) | pooled | **0.3835** | 1.00 |
| Blind portfolio (ignore the clues) | none | 0.5000 | 8.00 |
| Equal-split market (water-filling equilibrium) | pooled | 0.5991 | 2.67 |
| Private clues (everyone follows their own) | local | 0.8322 | 6.16 |
| Planner portfolio (top eight, one each) | pooled | **0.8594** | 8.00 |

Pooling improves the ranking (best single guess: 0.20 → 0.3835) while the
one-answer protocol destroys coverage. Eight uninformed-but-distinct guesses
beat eight informed identical ones. In the proportional large-market limit
the ordering survives exactly: 0 < 0.500 < 0.547 < 0.847 < 0.874.

Other headline quantities, all exact: recovery budget L\* = 7; redundancy
identity NQ − G = E[(K−1)⁺]; mixed price of anarchy 2 − 1/N (extends to
no-regret dynamics via smoothness); sole-rescue rewards make every pure Nash
equilibrium first-best; the market overtakes private search at copying
probability c\* = 0.788462; mechanical adoption of the consensus pick is
monotonically harmful (G(a): 0.8322 → 0.3835, strictly decreasing).

## Reproduce everything

```bash
pip install -r requirements.txt
python verify_shared_discovery_v8_6.py
```

Runtime ≈ 3 minutes. The script re-derives every number above by exact
enumeration (490,314 count vectors reduced to 67 classes), solves the
Poisson water-filling limit to 12 digits, runs seeded Monte Carlo
convergence diagnostics, scans a 72-combination comparative-statics grid,
regenerates all figures and CSVs, and asserts each claim against hardcoded
values. It ends with `All v8.6 checks passed.` A captured run is in
[`verification_log.txt`](verification_log.txt).

The paper's Appendix D separates claim status into three tiers —
analytically established (theorems), exactly enumerated (canonical
numbers), and computational patterns (grid observations) — and the script
mirrors that taxonomy.
